## 📈 4. Formula Focus Mapping (All Numericals)

| Topic | Core Formula / Method Used | Common Pitfall |
| :--- | :--- | :--- |
| **t-test (1-sample)** | `$t = \frac{\bar{x} - \mu}{s / \sqrt{n}}$` | Wrong df (n-1) or α-level misread |
| **z-probability (Normal)** | Convert to z-score → lookup table | Wrong tail selection (P(x > a) vs P(x < a)) |
| **One-way ANOVA** | Between-group & within-group variance, F-ratio | Forgetting degree of freedom split |
| **Linear Regression** | `$y = a + bx$`, `$b = \frac{\Sigma xy}{\Sigma x^2}$` | Arithmetic errors in Σx² and Σxy |
| **Correlation (r)** | `$r = \frac{\Sigma(x−\bar{x})(y−\bar{y})}{\sqrt{\Sigma(x−\bar{x})^2\Sigma(y−\bar{y})^2}}$` | Sign of r misinterpreted |
| **Confidence Interval** | `$\bar{x} \pm z(\frac{\sigma}{\sqrt{n}})$` or `$t(\frac{s}{\sqrt{n}})$` | Wrong critical value for 95% vs 99% |
| **Standard Error (SE)** | `$SE = \frac{\sigma}{\sqrt{n}}$` | Using sample SD instead of population |
| **Poisson / Binomial** | `$P(X=k) = \frac{e^{-\lambda} \lambda^k}{k!}$` or `$\binom{n}{k} p^k(1-p)^{n-k}$` | Using wrong λ or converting per hour/minute |
| **Chi-square Test** | `$\chi^2 = \Sigma \frac{(O−E)^2}{E}$` | Missing expected frequencies total check |

# Analysis of Numerical Problems: STATISTICS FOR AI & DATA SCIENCE (Mumbai University)

Here’s a detailed analysis of the numerical problems found in your STATISTICS FOR ARTIFICIAL INTELLIGENCE AND DATA SCIENCE exam papers (as per the PDF):

## Key Numerical Problem Types (with examples)

### Standard Deviation & Mean Calculations
* Find the standard deviation of average temperatures over several days.
* Calculate mean, standard deviation, standard error, and confidence interval for a data set (marks, weights, etc.).
* Given means and standard deviations, compute probabilities for normal distribution scenarios (e.g., “Find `P(x>40)`” with `x ~ N(μ, σ)`).

### Hypothesis Testing
* Set up and solve hypothesis tests for claimed population averages (battery life, drug effectiveness, teaching method effect).
* State null/alternative hypotheses, calculate test statistics, use significance levels to decide outcomes.

### Regression & Correlation
* Compute correlation coefficient from supplied data tables.
* Find regression equations (e.g., simple linear regression from tabulated values—Time vs. Growth, or GPA vs. hours of study).
* Explain or compare regression vs. correlation with practical application data.

### Confidence Interval & Standard Error
* Estimate/interpret standard error (e.g., sample mean wage, children per household).
* Construct and interpret confidence intervals for sample data.

### ANOVA (Analysis of Variance)
* Solve one-way ANOVA for sample groups (e.g., training scores for operator teams).
* Write about dependent/independent variables and explanations.
* Solve problems using Kruskal-Wallis test and Friedman Test (non-parametric ANOVA alternatives).

### Chi-Square Test
* Analyze contingency tables (e.g., customer gender vs. shopping preference) for independence.
* Apply the Chi-Square Test and interpret results.

### Probability & Distribution
* Calculate probabilities using normal distribution, binomial distribution, and uniform distribution (e.g., bottle filling, battery lives, car speeds).
* Find probabilities for random variables between intervals.

### Frequency Distribution Tables
* Create frequency tables (e.g., weights of oranges, hours studied, test scores).
* Calculate range, class mark, interval frequency.

---

## Common Features

* Most numericals require real-world interpretation (e.g., hypothesis testing for claims, ANOVA for practical data samples, regression on experimental data).
* Data tables are frequently provided—be ready to plug in and compute statistics.
* Interpret results for significance (p-value, confidence intervals, test decision).
* Probability numericals often link to decision/statistical inference.

---

## Examples from the PDF

* Mean, standard deviation, confidence interval calculation for a list of scores or weights.
* Find probability that a normally distributed variable exceeds a threshold.
* Use sample data to set up and solve hypothesis tests (battery, blood pressure, drug claims).
* Linear regression equation fitting from a pairs dataset.
* Frequency, range, class interval calculations for grouped data.
* ANOVA, Kruskal-Wallis, Friedman Test application to training results.
* Construct/interpret histograms, scatterplots, QQ plots.

---

## How to Prepare Numericals

* Practice solving for all formulas above using both small and moderate-size data sets.
* Learn how to read, process, and extract values from provided data tables.
* Be comfortable with writing and interpreting null/alternative hypotheses for real-life claims.
* Review steps to decide significance (using t/z/F/Chi-square tables as needed).
* Practice building frequency tables and group-based statistics.
* Make sure you can compute (by hand or calculator) all outlined statistics under time pressure.

---

## Short List of Most Frequent and Important Numericals

* Standard deviation and confidence intervals (sample data)
* Hypothesis test for sample mean vs claimed mean
* Correlation coefficient and regression line from tabulated data
* One-way ANOVA and non-parametric alternatives
* Probability calculations with normal, binomial, and uniform distributions
* Chi-square tests for contingency tables
* Frequency-distribution table construction

These numericals dominate past papers and carry strong predictive value for your upcoming exam. Focus your revision and practice on these!
